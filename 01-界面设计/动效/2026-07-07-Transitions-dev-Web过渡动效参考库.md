# Transitions.dev Web 过渡动效参考库

## 一句话价值

一个专门收集 Web UI 过渡动效的参考库，既能直接复制 CSS，也能通过 agent skill 帮 AI 生成更自然的界面动画。

## 内容摘要

Transitions.dev 收集了多种 Web 界面过渡效果，页面主张是 “Smooth transitions in seconds”。它不是泛泛的动效灵感站，而是围绕实际落地提供三类能力：

1. 浏览常见 UI 过渡动效，查看效果和实现思路。
2. 复制 CSS 代码，快速迁移到项目中。
3. 提供 agent skill 和 refine 工具，让 AI agent 能更好地实现、调整和生成动画。

站点关联的 GitHub 仓库是 `Jakubantalik/transitions.dev`，项目说明强调 “Copy CSS, use the agent skill, refine motion with AI.”

## 为什么值得收藏

1. 页面过渡和组件动效是前端质感的关键，但很容易做得生硬；这个库可以作为动效节奏参考。
2. 它同时服务设计师、开发者和 AI agent，适合放进自己的 AI 前端工作流。
3. 可复制 CSS 使它不只是灵感站，而是能快速迁移到项目里的素材库。
4. agent skill 的存在适合后续整理成 Codex / Cursor / Claude Code 的前端动效规则。
5. 对 glint.red 这类需要更高界面完成度的项目，可以作为页面切换、卡片入场、菜单展开和局部状态变化参考。

## 未来可以怎么用

- 做 landing page 或产品页时，用它挑选页面入场、卡片出现、菜单展开、内容切换等过渡效果。
- 写前端 prompt 时，把它作为“动效参考来源”，要求 agent 遵循其中的节奏、时长和 easing。
- 把其中好用的 transition 模式拆成自己的组件规范：进入、退出、展开、收起、hover、focus、route change。
- 和 Border Beam、Dynamic Island Header、收藏按钮流光效果一起，整理成“小面积动效 + 页面过渡”的 UI 动效库。
- 后续如果有时间，可以单独把它的 agent skill 拆出来做 Codex 能力卡片。
