| 项目 | 选用说明 |

| 优先选用条件 | 写具体任务、项目阶段和目标产物，避免只写“提升质感”“支持当前项目”。 |
| 不适合或暂缓条件 | 写真正会影响选型的不匹配情境；资料不足标注待确认，不编造排除理由。 |
| 复用方式 | 从视觉参考、复制源码、安装依赖、读取 Skill、套用方法、使用服务、查询入口等选择实际可用方式；可多选。 |

| 首次读取入口 | 用相对 Markdown 链接定位原卡章节、本地备份文件或官方文档；不能只写“看官网”。 |
| 同类选择依据 | 比较库内相近素材：在什么条件下选谁；用相对 Markdown 链接指向原卡。没有可比素材就说明，不强行配对。 |
